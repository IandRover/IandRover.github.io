# CV

Typst sources for my academic CV and industry resume.

## Build

```bash
cd ~/Documents/IandRover.github.io/CV
typst compile cv_academic.typ ChiaHsiang_Kao_CV.pdf
typst compile resume_industry.typ ChiaHsiang_Kao_Resume.pdf
```

Live preview (rebuilds on every save):

```bash
typst watch cv_academic.typ ChiaHsiang_Kao_CV.pdf
```

Install Typst with `brew install typst`.
